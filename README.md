# Waterfront Trips Report

Bookmarklet script for harbourridge.com that lists upcoming Water Shuttle / Waterfront trips with headcounts, and a Members button per trip showing who's registered with tap-to-call phone numbers.

The bookmark is a small loader that fetches `waterfront.js` from this repo and runs it on the current harbourridge.com tab. Edit `waterfront.js` here to update every device that uses the bookmark.
