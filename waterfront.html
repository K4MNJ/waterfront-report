Waterfront Trips Report

Live report of Water Shuttle / Waterfront trips and headcounts, pulled from the Harbour Ridge member calendar API.
This bookmark only works when clicked from a harbourridge.com tab. It has to run in that tab to use your login session — this instructions page (whether opened as a local file or hosted anywhere else) is a different origin, so clicking the bookmark from here will fail (you'll see a CORS / "Failed to fetch" error, or a 401). That's expected. Drag it to your bookmarks bar from here, then go click it from harbourridge.com itself. The bookmark now also checks which site you're on and shows a clear alert if you click it anywhere else.

Set it up (one time)

  1. Make sure your browser's bookmarks bar is visible (in Chrome: Cmd/Ctrl+Shift+B).
  2. Drag the button below up onto your bookmarks bar.
  3. The bookmark is a small loader. Each time you click it, it downloads the latest report script from github.com/K4MNJ/waterfront-report, so updates there reach every device without re-adding the bookmark.
📋 Waterfront Trips Report

Use it

  1. Open a new tab and go to harbourridge.com. Make sure you're logged in and the address bar shows harbourridge.com.
  2. From that tab, click the Waterfront Trips Report bookmark in your bookmarks bar.
  3. A panel appears in the top-right of the page with a Range dropdown (This week / Next week / This month / Next month, defaults to This month) and a live table of trips with headcounts.
  4. Click Members on any trip to show who's registered (each booker with their party size, and the people in their party underneath) with phone numbers. Click Hide to collapse it. Phone numbers are tap-to-call links.
  5. On a phone, the panel fills the screen and shows each trip as a card instead of a table.
  6. Change the dropdown or click Refresh to reload; click the ✕ to close the panel.

Alternative: paste into the console

If your browser strips bookmarklets or you'd rather not add one, open DevTools on a harbourridge.com tab (F12 or Cmd/Ctrl+Option+I), go to the Console tab, paste the snippet below, and press Enter. It loads the latest script from GitHub, the same as the bookmark.

fetch("https://raw.githubusercontent.com/K4MNJ/waterfront-report/main/waterfront.js", { cache: "no-store" })
  .then(function (r) { if (!r.ok) throw new Error("HTTP " + r.status); return r.text(); })
  .then(function (s) { (0, eval)(s); });
No cross-check against the registrants API is performed — headcounts come straight from GetClubCalendar's totalHeadCount field. The Members list comes from the event's registrants API (waitlist excluded). If a phone number isn't in that data, it's looked up in the member directory. Guests without a member profile show —.

Set it up on a phone

Open this page on the phone, copy the bookmark code, then save it as a bookmark in the phone's browser.

If Copy doesn't work, tap inside the box, choose Select all, then Copy.

Android (Chrome)

  1. Open any page on harbourridge.com. Tap ⋮, then the ☆ star to bookmark it.
  2. Tap Edit in the pop-up at the bottom (or ⋮ → Bookmarks, then the bookmark's ⋮ → Edit).
  3. Name it Waterfront Trips Report. Clear the URL field, paste the code, and tap back to save.
  4. To run it: on harbourridge.com, type Waterfront in the address bar and tap the suggestion with the ☆ icon. Opening it from the Bookmarks list does nothing on Android.

iPhone (Safari)

  1. Open any page on harbourridge.com. Tap the Share button, then Add Bookmark, and save it.
  2. Tap the Bookmarks (book) icon, then Edit, and tap the new bookmark.
  3. Name it Waterfront Trips Report. Clear the address field, paste the code, and tap Done.
  4. To run it: on harbourridge.com, open Bookmarks and tap Waterfront Trips Report.
